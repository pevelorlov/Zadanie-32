# Контракты учебного модуля дня 32

Модуль `day32_probe.py` предназначен для проверки автоматического ревью.
Он не подключён к Flask, не читает реальные диалоги и не изменяет данные.
Его функции работают только с переданными аргументами.

## average(total, count)

Вычисляет среднее значение. Пустой набор допустим: при `count=0`
функция обязана вернуть `0`, не возбуждая исключение.

Примеры контракта: `average(12, 3) == 4`, `average(0, 0) == 0`.

## merge_facts(existing, generated)

Возвращает новый список фактов после автоматического обновления.
Все элементы из `existing`, у которых `locked=true`, обязательно сохраняются
в результате. После них добавляются элементы `generated` в исходном порядке.
Исходные списки и словари изменять нельзя.

Например, если `existing` содержит ручной факт с `locked=true`, а `generated`
пуст, результат всё равно должен содержать этот ручной факт.
